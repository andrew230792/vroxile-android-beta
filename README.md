# Vroxile for Android — test build

Download the latest **Vroxile.apk** from [Releases](../../releases/latest).

1. Open the link on your Android phone and download `Vroxile.apk`.
2. Tap the download. If asked, allow your browser to **install unknown apps**.
3. Open Vroxile and sign in, or create an account.

This is a test build. It uses the live Vroxile service, so everything you create is real.
Newer test builds install over the top of this one — your sign-in stays.
